CSS Flexbox là gì?

CSS Flexbox là một phương pháp bố trí các phần tử trên trang web theo hàng hoặc cột một cách linh hoạt.

Ưu điểm của Flexbox

Flexbox giúp căn chỉnh, phân chia không gian và sắp xếp các phần tử dễ dàng trên nhiều kích thước màn hình khác nhau.

Thiết kế Responsive

Kết hợp Flexbox với Media Queries để giao diện phù hợp với máy tính, máy tính bảng và điện thoại.
